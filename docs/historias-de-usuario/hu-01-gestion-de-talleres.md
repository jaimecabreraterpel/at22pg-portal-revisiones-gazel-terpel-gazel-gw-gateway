### HU 01 – Gestión de talleres

| Descripción | Este documento describe las funcionalidades del módulo de administración de talleres, permitiendo a los administradores crear, consultar, editar y gestionar el estado de los talleres del sistema, de acuerdo con los roles definidos. |
| --- | --- |
| Yo Como | Usuario Administrador |
| Quiero | Gestionar, crear y editar talleres dentro del sistema |
| Para | Facilitar la gestión de talleres dentro del sistema |
| Pre-Condición | Ser un usuario con rol administrador |
