### HU 01.3 – Gestión de roles

| Descripción | Este documento detalla las funcionalidades que permiten a un usuario administrador crear, editar y visualizar roles, así como asignar permisos por módulo, incluyendo criterios de aceptación, escenarios de uso y validaciones necesarias para garantizar una correcta gestión de accesos. |
| --- | --- |
| Yo Como | Usuario Administrador |
| Quiero | Gestionar, crear y editar roles dentro del sistema |
| Para | Facilitar la gestión de los roles dentro del sistema |
| Pre-Condición | Ser un usuario con rol administrador |
| Criterios de Aceptación | Escenario 0 Visualización modulo gestión de roles <br>Dado que: Un usuario administrador <br>Cuando: Ingresar al módulo gestión de roles <br>Entonces: Se debe visualizar la siguiente información: <br>Título “Gestión de roles”<br>Campo “seleccionar rol” (Lista desplegable)<br>Botón “Editar”<br>Botón “Crear rol”<br>Y, además: Se espera visualizar una tabla con los siguientes campos: <br>Modulo <br>Edición <br>Registro<br>Aprobación <br>Consulta <br>Generación de reportes<br>Y, además: Se deben visualizar máximo 20 registros de manera predeterminada y se debe  <br>Contar con una casilla para seleccionar cuantos registros se espera visualizar de 10 en 10 y se debe contar con su respectiva paginación y navegación (Ver imagen). <br>___________________________________________________________________________ <br>Escenario 1 Creación de rol<br> <br>Dado que: Un usuario administrador <br>Cuando: Ingresar al módulo gestión de roles y da clic en el botón “Crear rol”<br>Entonces: Se debe visualizar la siguiente información: <br>Título “Gestión de roles”<br>Campo “Nombre del rol” <br>Y, además: Se espera visualizar una tabla con los siguientes campos en donde se espera contar con radio buttons para asignar cada permiso al rol que se está creando: <br>Nombre del Modulo <br>Edición <br>Registro<br>Aprobación <br>Consulta <br>Generación de reportes<br>Botón “Regresar”<br>Botón “Crear rol”<br>Y, además: Al dar clic en el botón “Crear rol” se debe visualizar el siguiente popup de confirmación: ¿Estás seguro de que deseas crear el rol “Rol”? con las siguientes opciones “Registrar” y “Cancelar”. <br>Y, además: Si da clic en el botón “Registrar” se debe visualizar el siguiente mensaje de éxito ¡Rol “Rol” creado con éxito!<br>Y, además: Si da clic en el botón “Cancelar” se debe dirigir al usuario a la pantalla principal de gestión de roles <br>___________________________________________________________________________<br>Escenario 2 Edición permisos por rol<br>Dado que: Un usuario administrador <br>Cuando: Ingresar al módulo gestión de roles, selecciona un rol y da clic en el botón “Editar rol”<br>Entonces: Se debe visualizar la siguiente información: <br>Título “Gestión de roles” <br>Campo “Nombre del rol” <br>Y, además: Se espera visualizar una tabla con los siguientes campos en donde se espera contar con radio buttons para editar cada permiso al rol que se está editando: <br>Nombre del Modulo <br>Edición <br>Registro<br>Aprobación <br>Consulta <br>Generación de reportes<br>Botón “Guardar”<br>Y, además: Al dar clic en el botón “Editar” se debe visualizar el siguiente popup de confirmación: ¿Estás seguro de que deseas cambiar los accesos de este rol? con las siguientes opciones “Guardar” y “Cancelar”. <br>Y, además: Si da clic en el botón “Guardar” se debe visualizar el siguiente mensaje de éxito ¡Cambios guardados con éxito!<br>Y, además: Si da clic en el botón “Cancelar” se debe dirigir al usuario a la pantalla principal de gestión de roles<br>___________________________________________________________________________<br>Escenario 3 Auditoría de cambios<br>Dado que: Soy un administrador que ha realizado algun cambio<br>Cuando: El sistema guarda los cambios<br>Entonces: Registra automáticamente el usuario que realizó la acción, fecha/hora, valores anteriores/nuevos y zona<br>Y, además: Esta información de auditoría puede ser consultada posteriormente en la base de datos |
