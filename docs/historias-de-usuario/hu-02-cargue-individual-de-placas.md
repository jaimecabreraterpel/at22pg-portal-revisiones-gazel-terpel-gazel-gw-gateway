### HU  02 – Cargue individual de placas

| Descripción | El sistema debe permitir que un administrador cargar placas de vehículos de forma individual para los programas disponibles, validando que tengan el formato correcto según el tipo de vehículo (3 letras y 3 números o 3 letras 2 números y 1 letra o 17 caracteres alfanuméricos) y mostrando mensajes claros sobre el resultado de la operación. |
| --- | --- |
| Yo Como | Usuario Administrador |
| Quiero | Cargar y habilitar placas de forma individual en la plataforma para cada uno de los programas (Altos Consumidores, Vencidos y PAP) |
| Para | Controlar qué vehículos pueden acceder a los beneficios de cada programa |
| Pre-Condición | El usuario debe tener rol de administrador<br>El usuario debe estar autenticado en el sistema |
