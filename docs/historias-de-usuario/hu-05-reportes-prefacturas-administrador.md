### HU  05 – Reportes pre-facturas usuario administrador

| Descripción | El sistema debe proporcionar una funcionalidad que permita al usuario administrador consultar y descargar información detallada de los servicios registrados por los talleres y certificadores para los diferentes programas (PAP, Vencidos y Altos Consumidores). Esta información es necesaria para generar los pagos correspondientes a los servicios prestados. |
| --- | --- |
| Yo Como | Administrador |
| Quiero | Consultar y descargar reportes de pre-facturas para los programas vigentes PAP, Vencidos y Altos Consumidores |
| Para | Generar los pagos correspondientes a los servicios prestados |
| Pre-Condición | Usuario con rol administrador<br>Existencia de servicios registrados en el sistema |

siguiente información en la pantalla Reportes pre-facturas:<br>Título “Reportes pre-facturas”<br>Filtros:<br>Año (lista desplegable)<br>Rango de fechas (Campo tipo calendario)<br>Programa (lista desplegable)<br>Regional (lista desplegable)<br>Taller (lista desplegable)<br>Estado (Lista desplegable)<br>Botón “Consultar”<br>Botón “Limpiar filtros”<br>Secciones en la misma pantalla “Aprobado”, <br>____________________________________________________________________<br>Escenario 4: Botón “Ver más”  <br>Dado que un usuario administrador y realiza una consulta de reportes de
