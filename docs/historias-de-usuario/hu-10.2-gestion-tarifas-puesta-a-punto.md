### HU 10.2 – Gestión tarifas Puesta a punto

| Descripción | El sistema debe permitir al administrador consultar, registrar y actualizar tarifas. Las tarifas deben mostrar información detallada además debe garantizar vigencias correctas, evitar solapamientos y mantener tarifas independientes para talleres y certificadores. También debe conservar historial de cambios para auditoría. Además, permite carga masiva de tarifas mediante archivos Excel/CSV. |
| --- | --- |
| Yo Como | Administrador |
| Quiero | Visualizar, registrar, actualizar y eliminar las tarifas de los servicios por programa, certificador y zona |
| Para | Asegurar que los valores utilizados en los cálculos de prefecturas, pagos e indicadores sean correctos, vigentes y controlados. |
| Pre-Condición | El usuario debe estar autenticado y tener rol Administrador |
