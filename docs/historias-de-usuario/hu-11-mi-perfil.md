### HU 11 – Mi perfil

| Descripción | Esta historia de usuario permite a cualquier usuario autenticado del sistema visualizar y gestionar su información personal dentro de la plataforma. El usuario podrá acceder a una sección específica denominada "Mi Perfil" donde se mostrará su información básica como rol asignado, nombre completo y correo electrónico. |
| --- | --- |
| Yo Como | Usuario Administrador, Analista Técnico, Comercial, Distribuidora, taller y certificadores |
| Quiero | Ver y gestionar mi información personal, incluyendo datos de perfil, contraseña y datos de contacto |
| Para | Para mantener mis datos actualizados y acceder al sistema de manera segura. |
| Pre-Condición | Ser un usuario autenticado en el sistema<br>Tener credenciales válidas |
| Criterios de Aceptación | Escenario 0 Visualización pantalla mi perfil<br>Dado que: Soy un usuario autenticado en el sistema<br>Cuando: Accedo al módulo "Mi Perfil"<br>Entonces: Se debe visualizar la pantalla de mi perfil con la siguiente información: <br>Título “Hola “Nombre del usuario””<br>Campo de imagen (archivos permitidos PNG y JPNG)<br>Sección Datos de perfil con la siguiente información <br>botón “Actualizar datos”<br>Rol <br>Nombre<br>Teléfono <br>Correo<br>sección Contraseña con los siguientes campos: <br>Contraseña actual (Ingresar la contraseña actual)<br>Nueva contraseña (Definir los caracteres que debe contener en términos de cantidad, especiales y demás)<br>Confirmar nueva contraseña (Debe validar que la contraseña ingresada sea igual a la del campo anterior “Nueva contraseña”)<br>botón “Actualizar contraseña”
